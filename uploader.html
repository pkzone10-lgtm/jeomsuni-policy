shorts-pipeline 개인정보 처리방침

shorts-pipeline 은 운영자 본인이 자기 유튜브 채널(이순 耳順, 살아보니)에 영상을 올리고 통계를 보기 위해 쓰는 개인용 도구입니다. 다른 사람에게 제공하지 않습니다.

도구는 운영자가 로그인한 유튜브 계정에 대해서만 영상 업로드·예약, 고정 댓글, 채널·영상 통계 읽기를 합니다. 받은 로그인 정보(토큰)는 운영자의 컴퓨터에만 저장되며 다른 곳으로 보내거나 다른 사람과 공유하지 않습니다.

Google API 에서 받은 정보의 사용은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 따릅니다.
